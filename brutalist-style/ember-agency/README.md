# Ember Agency

Landing page creative agency dengan arah neo-brutalist editorial: tipografi display berukuran besar, grid tegas, kontras hitam-putih, dan aksen oranye yang agresif.

## Structure

- `index.html` — entry point landing page.
- `assets/css/` — design tokens, global styles, components, dan responsive rules.
- `assets/js/main.js` — smooth scrolling, menu mobile, reveal animation, dan interaksi halaman.
- `docs/` — dokumentasi arsitektur, desain, dan spesifikasi.

## Run

Buka `index.html` secara langsung atau jalankan static server dari root repository.
