# Limeframe Studio

Landing page untuk digital marketing studio dengan pendekatan neon editorial brutalism: komposisi asimetris, panel hitam, garis tegas, ilustrasi SVG, dan aksen lime yang terasa seperti highlighter.

## Teknologi

- HTML5 semantik
- CSS3 tanpa framework
- Vanilla JavaScript
- Inline SVG illustration
- Google Fonts via CDN

Tidak diperlukan proses build atau dependency lokal. Halaman dapat dibuka langsung melalui browser atau static server.

## Struktur

```text
limeframe-studio/
├── index.html
├── assets/
│   ├── css/
│   │   ├── variable.css
│   │   ├── global.css
│   │   ├── components.css
│   │   └── responsive.css
│   └── js/
│       └── main.js
└── docs/
```

## Menjalankan

Buka `index.html` secara langsung, atau jalankan:

```bash
python -m http.server 8000
```

Kemudian buka `http://localhost:8000`.
